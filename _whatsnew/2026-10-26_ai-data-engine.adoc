[[ai-data-engine-1-3]]
=== AI Data Engine 1.3

AI Data Engine 1.3 est la première version en disponibilité générale (GA) de AI Data Engine (AIDE), un service d'intelligence des métadonnées géré via la NetApp Console. AIDE analyse vos systèmes connectés, crée un catalogue de métadonnées et vous offre la visibilité et les outils nécessaires pour optimiser le stockage et gérer les données à grande échelle. Pour en savoir plus, reportez-vous à https://docs.netapp.com/us-en/ai-data-engine/get-started/learn-about.html["Découvrez AI Data Engine"^].



[[optimize-storage-and-investigate-your-data]]
=== Optimisez le stockage et analysez vos données

Vous pouvez identifier les données froides, obsolètes et dupliquées sur vos systèmes connectés, trouver les répertoires aux permissions ouvertes et examiner les tables de base de données surdimensionnées ou inutilisées. Vous pouvez agir directement sur les résultats ou enregistrer les critères de filtrage sous forme de stratégies qui surveillent l’état des données au fil du temps. Pour en savoir plus, consultez https://docs.netapp.com/us-en/ai-data-engine/release-notes/whats-new.html["Nouveautés dans AI Data Engine"^].



[[govern-ai-access-to-your-metadata]]
=== Gérez l'accès de l'IA à vos métadonnées

Vous pouvez connecter des clients d'IA à AI Data Engine via le protocole MCP (Model Context Protocol) et utiliser les portées Microsoft Entra ID pour contrôler qui peut effectuer des recherches dans chaque collection. Pour en savoir plus, consultez https://docs.netapp.com/us-en/ai-data-engine/mcp/learn-about-mcp.html["Découvrez le MCP dans AI Data Engine"^].
