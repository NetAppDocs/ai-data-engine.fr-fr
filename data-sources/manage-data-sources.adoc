= Gérer les sources de données dans AI Data Engine
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Une fois les sources de données connectées, vous pouvez suivre l'état de leur analyse et les gérer depuis l'onglet *Systèmes analysés*. Utilisez ces procédures pour suspendre ou reprendre l'analyse, mettre à jour les paramètres d'authentification, ajuster les paramètres d'accès aux données et désactiver les systèmes que vous n'avez plus besoin d'analyser.



[[view-scan-status-and-details]]
== Afficher l'état et les détails de l'analyse

.Étapes
. Dans l’interface utilisateur de AI Data Engine, sélectionnez *Configuration*.
. Dans l'onglet *Systèmes analysés*, repérez le système que vous souhaitez examiner.
. Sélectionnez la ligne du système pour ouvrir la vue détaillée.
+
La vue détaillée affiche :

+
** Aperçu de l’état avec la progression actuelle de l’analyse
** Répartition des états d’analyse des ressources de données : en cours, terminée, en pause et erreurs
** Mode d'autorisation d'analyse (par exemple, « Analyse sans autorisations d'écriture »)
+
Si des erreurs d'analyse apparaissent, développez les détails de l'erreur pour voir quels volumes ou partages sont affectés et la raison de l'échec.







[[pause-scanning]]
== Suspendre l’analyse

.Étapes
. Dans l’interface utilisateur de AI Data Engine, sélectionnez *Configuration*.
. Dans l'onglet *Systèmes analysés*, repérez le système que vous souhaitez mettre en pause.
. Sélectionnez la ligne du système pour ouvrir la vue détaillée.
. Sélectionnez *Pause*.




[[resume-scanning]]
== Reprendre la numérisation

.Étapes
. Dans l’interface utilisateur de AI Data Engine, sélectionnez *Configuration*.
. Dans l’onglet *Systèmes analysés*, repérez le système en pause.
. Sélectionnez la ligne du système pour ouvrir la vue détaillée.
. Sélectionnez *Resume*.




[[scan-all-data-resources]]
== Analyser toutes les ressources de données

Déclenchez une analyse immédiate de toutes les ressources de données d'un système. Utilisez cette fonction pour actualiser les métadonnées après une modification importante des données.

.Étapes
. Dans l’interface utilisateur de AI Data Engine, sélectionnez *Configuration*.
. Dans l'onglet *Systèmes analysés*, repérez le système que vous souhaitez analyser.
. Sélectionnez le menu Actions à côté du système.
. Sélectionnez *Analyser tous les volumes* (il existe une option équivalente dans le menu Actions pour les partages et les compartiments).




[[retry-failed-scans]]
== Réessayer les analyses ayant échoué

Remettez en file d'attente les ressources de données qui sont dans un état d'échec ou d'erreur. Résolvez d'abord la cause première, comme un problème d'identifiant, une erreur réseau ou un problème d'autorisation, avant de réessayer.

.Étapes
. Dans l’interface utilisateur de AI Data Engine, sélectionnez *Configuration*.
. Dans l’onglet *Systèmes analysés*, repérez le système dont l’analyse a échoué.
. Sélectionnez le menu Actions à côté du système.
. Sélectionnez *Réessayer toutes les analyses*.




[[edit-cifs-credentials]]
== Modifier les identifiants CIFS

Mettez à jour les identifiants qu’AI Data Engine utilise pour s’authentifier auprès des partages SMB/CIFS.

.Étapes
. Dans l’interface utilisateur de AI Data Engine, sélectionnez *Configuration*.
. Dans l'onglet *Systèmes analysés*, repérez le système SMB/CIFS.
. Sélectionnez la ligne du système pour ouvrir la vue détaillée.
. Sélectionnez *Modifier les identifiants CIFS*.
. Saisissez le nom d'utilisateur et le mot de passe mis à jour, puis sélectionnez *Enregistrer*.




[[enable-or-disable-access-to-dp-volumes]]
== Activer ou désactiver l'accès aux volumes DP

Les volumes de protection des données (DP) sont des volumes de destination NetApp SnapMirror. Par défaut, AI Data Engine n'analyse pas les volumes DP. Vous pouvez activer ou désactiver l'accès aux volumes DP pour chaque système.

.Étapes
. Dans l’interface utilisateur de AI Data Engine, sélectionnez *Configuration*.
. Dans l’onglet *Systèmes analysés*, localisez le système.
. Sélectionnez la ligne du système pour ouvrir la vue détaillée.
. Sélectionnez *Activer l'accès aux volumes DP* ou *Désactiver l'accès aux volumes DP*.




[[enable-or-disable-scanning-of-specific-shares-buckets-or-volumes]]
== Activer ou désactiver l’analyse de partages, de compartiments ou de volumes spécifiques

Après avoir connecté et analysé une source de données, vous pouvez activer ou désactiver l'analyse pour des volumes ou des partages individuels sans reconfigurer l'ensemble du système. Utilisez cette fonctionnalité pour affiner le périmètre d'analyse après la configuration initiale. Par exemple, vous pouvez exclure les volumes contenant des données que vous n'avez pas besoin d'analyser, ou ajouter des volumes qui n'étaient pas sélectionnés ou disponibles lors de l'analyse initiale.

.Étapes
. Dans l’interface utilisateur de AI Data Engine, sélectionnez *Configuration*.
. Dans l'onglet *Systèmes analysés*, repérez le système que vous souhaitez mettre à jour.
. Sélectionnez *Afficher les détails* dans la ligne du système.
. Dans la liste des ressources de données, repérez le volume, le compartiment ou le partage que vous souhaitez modifier.
. Utilisez le bouton *Scanning* pour activer ou désactiver l’analyse de cette ressource.




[[deactivate-ai-data-engine-for-a-system]]
== Désactiver AI Data Engine pour un système

La désactivation d'un système interrompt toute analyse et le retire de la couverture d’analyse active. La configuration du système est conservée et vous pouvez le réactiver à tout moment en sélectionnant *Activate scans* sur la ligne du système.

.Étapes
. Dans l’interface utilisateur de AI Data Engine, sélectionnez *Configuration*.
. Dans l'onglet *Systèmes analysés*, repérez le système que vous souhaitez désactiver.
. Sélectionnez le menu Actions à côté du système.
. Sélectionnez *Désactiver AI Data Engine*.
