= Déployer AI Data Engine Enterprise
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Déployez AIDE Enterprise depuis NetApp Console à l’aide de l’assistant de déploiement. L’assistant vous guide dans la sélection de l’emplacement d’installation, le choix d’une taille de configuration et l’exécution de la commande d’installation sur votre cluster RKE2.

.Avant de commencer
* Vous disposez des autorisations d’_administrateur de l’organisation_ ou supérieures dans NetApp Console.
* Votre cluster RKE2 répond aux prérequis du nœud Enterprise décrits dans link:aide-requirements.html["exigences AIDE"].
* Les autorisations sudo (ou root) sont requises sur la machine à partir de laquelle vous exécutez la commande d'installation.
* Un serveur NFS avec un chemin exporté est disponible et accessible depuis le cluster pour le volume de configuration AIDE.
* Un agent NetApp Console https://docs.netapp.com/us-en/console-setup-admin/concept-agent-install-options.html#agent-console-deploy["est déployé"^] est requis et doit être accessible depuis les nœuds du cluster. L’adresse IP de l’agent Console est nécessaire pour exécuter la commande d’installation.
* kubectl est disponible sur la machine à partir de laquelle vous exécutez la commande d'installation, avec un accès cluster-admin au cluster cible.
* L'espace de noms Kubernetes cible (par défaut `aide`) existe déjà sur le cluster avant que vous n'exécutiez la commande d'installation.
* Une StorageClass configurée (nom par défaut : `aide-sc`) est disponible sur le cluster et utilisée pour les services de support avec état d’AIDE.


.Étapes
. Dans NetApp Console, accédez à *Gouvernance* > *AI Data Engine*.
+
La page d'accueil de AI Data Engine s'affiche.

. Sélectionnez *Deploy AI Data Engine*.
. Sélectionnez l’option de déploiement *Enterprise* et sélectionnez *Next*.
. Copiez la commande d'installation préconfigurée affichée dans l'assistant dans un éditeur.
. Sélectionnez la taille de votre configuration :
+
** *Petit* : recommandé pour les environnements contenant jusqu’à environ 1 milliard de fichiers.
** *Moyen (Par défaut)* : recommandé pour les environnements contenant jusqu’à environ 3 milliards de fichiers.
** *Grande* : recommandé pour les environnements contenant jusqu’à environ 6 milliards de fichiers.
+
Ces tailles sont des recommandations de base, et non des limites strictes. AIDE Enterprise prend en charge les environnements de plus de 6 milliards de fichiers grâce à une extension horizontale ; consultez link:aide-requirements.html#flexible-sizing-enterprise["directives de dimensionnement flexibles"] pour plus de détails.



. Pour les petites ou grandes configurations, ajustez la commande d'installation en fonction de la taille choisie : `--flavor <small|medium|large>`
. Exécutez la commande d’installation avec tous les ajustements de taille de configuration requis depuis votre hôte cible disposant d’un accès kubectl à votre cluster RKE2.
+

NOTE: L'installation prend environ 30 minutes. Des délais d'attente et des tentatives de reconnexion peuvent survenir, ce qui est normal.

. Lorsque vous y êtes invité, confirmez l'adresse IP de l'hôte et l'identifiant de l'utilisateur pour poursuivre l'installation.
. Surveillez l'écran de progression jusqu'à ce que l'écran de réussite apparaisse et affiche « AI Data Engine déployé ».


.Résultat
AI Data Engine Enterprise est déployé et connecté à NetApp Console. Vous pouvez maintenant link:../data-sources/connect-data-source.html["connecter une source de données"] lancer l'analyse.
