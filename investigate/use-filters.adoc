= Filtres de métadonnées dans AI Data Engine
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La vue Investigation de AI Data Engine fournit des filtres de métadonnées pour affiner vos résultats à un groupe de données spécifique. Appliquez simultanément un ou plusieurs filtres pour définir les fichiers que vous souhaitez examiner ou sur lesquels vous souhaitez agir.



[[time-filters]]
== Filtres temporels

[cols="1,2"]
|===
| Filtre | Description 


| Dernier créé | Filtrez les fichiers par date de création. 


| Dernière modification | Filtrez les fichiers par la date de leur dernière modification. 


| Dernier accès | Filtrez les fichiers selon la date de leur dernier accès. Utilisez ce filtre pour identifier les données froides ou obsolètes. 


| Heure de découverte | Filtrez les fichiers selon la date à laquelle AI Data Engine les a détectés pour la première fois lors de l’analyse. 
|===


[[file-attribute-filters]]
== Filtres d'attributs de fichier

[cols="1,2"]
|===
| Filtre | Description 


| Type de fichier | Filtrez par extension de fichier ou par classification de type. Sélectionnez un ou plusieurs types de fichiers dans la liste. 


| Taille du fichier | Filtrer par taille de fichier. Saisissez une valeur minimale, une valeur maximale ou une plage. 


| Chemin d’accès au fichier/répertoire | Filtrer par le chemin complet ou partiel du fichier ou de son répertoire parent. 


| Propriétaire du fichier/répertoire | Filtrer par l’utilisateur ou le groupe propriétaire du fichier ou du répertoire. 


| Hachage du fichier | Filtrez par valeur de hachage d'un fichier pour trouver des fichiers spécifiques ou confirmer un contenu en double. 


| Doublons | Filtrer pour n'afficher que les fichiers présentant des copies en double détectées dans le catalogue. 


| Type de répertoire | Filtrer par type de répertoire. S'applique à l'onglet Répertoires. 
|===


[[source-filters]]
== Filtres de source

[cols="1,2"]
|===
| Filtre | Description 


| Conteneur de données | Filtrez sur un volume ou un partage spécifique. 


| Système | Filtrer vers un cluster spécifique. 


| Type de système | Filtrer par le type de système de stockage. 
|===


[[governance-filters]]
== Filtres de gouvernance

[cols="1,2"]
|===
| Filtre | Description 


| Étiquettes | Filtrez les fichiers auxquels une étiquette commerciale spécifique est appliquée. 


| Politique | Filtrez les fichiers qui correspondent à une stratégie enregistrée spécifique. Les noms des stratégies apparaissent dans la liste des filtres. 
|===


[[access-filters]]
== Filtres d'accès

[cols="1,2"]
|===
| Filtre | Description 


| Nombre d'utilisateurs ayant accès | Filtrez les fichiers en fonction du nombre d'utilisateurs ou de groupes qui y ont accès. Utilisez cette fonction pour identifier les données largement accessibles. 


| Autorisations des utilisateurs/groupes | Filtrez les fichiers par utilisateur ou groupe spécifique disposant des autorisations d'accès. 
|===


[[combining-filters]]
== Combiner des filtres

Les filtres sont combinés avec une logique ET, ce qui signifie que les résultats doivent correspondre à tous les filtres appliqués simultanément.
