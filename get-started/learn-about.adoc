= Découvrez AI Data Engine
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AI Data Engine (AIDE) est un service d’intelligence des métadonnées qui vous offre une visibilité sur les données structurées et non structurées stockées sur vos systèmes de stockage. AI Data Engine analyse vos systèmes de stockage et catalogue les métadonnées du système de fichiers afin que vous puissiez identifier les opportunités d’optimisation du stockage, explorer vos données et appliquer des politiques de gouvernance.



[[what-ai-data-engine-does]]
== Ce que fait AI Data Engine

AI Data Engine analyse les sources de données que vous connectez et crée un catalogue de métadonnées consultable, mis à jour à chaque cycle d'analyse. À partir de ce catalogue, vous pouvez :

* *Comprenez votre espace de stockage.* Découvrez la quantité de données que vous possédez, qui en est le propriétaire et où elles se trouvent.
* *Récupérez de la capacité.* Identifiez les données inactives, obsolètes et dupliquées, et voyez quels propriétaires de données en détiennent le plus, afin de savoir qui contacter pour le nettoyage.
* *Identifier les risques d'accès.* Repérer les répertoires disposant d'autorisations ouvertes afin de pouvoir les prioriser pour examen.
* *Analysez et organisez.* Utilisez des filtres de métadonnées pour trouver les données qui vous intéressent, étiquetez-les et enregistrez vos critères sous forme de politique que vous pourrez suivre au fil du temps.
* *Agissez sur les données.* Étiquetez, archivez, copiez ou supprimez les fichiers que vous avez consultés.
* *Préparez les données pour l'IA.* Permettez aux clients d'IA que vous avez autorisés de rechercher dans vos métadonnées et d'agir sur les données.




[[storage-optimization-and-data-lifecycle-management]]
== Optimisation du stockage et gestion du cycle de vie des données

Utilisez les métadonnées pour identifier les données qui justifient un examen, comme les fichiers qui atteignent les seuils de données froides et obsolètes de votre organisation et les fichiers dupliqués. Analysez les résultats avant de décider de conserver, d'étiqueter, d'archiver, de copier ou de supprimer les données.

Les analyses d’optimisation du stockage mettent en évidence des opportunités. La capacité que vous pourriez récupérer dépend des actions que vous choisissez d’entreprendre.



[[governed-ai-access]]
== Accès gouverné à l'IA

L'accès contrôlé à l'IA permet aux clients d'IA de rechercher vos métadonnées via le protocole Model Context Protocol (MCP), dans les limites que vous définissez. Vous choisissez les données à rendre disponibles en créant des collections. Une collection est un ensemble de données analysées que vous mettez à la disposition des clients d'IA. Vous contrôlez les collections qu'un utilisateur peut rechercher en définissant les scopes Microsoft Entra ID.

Les clients d'IA fonctionnent uniquement avec les métadonnées. Ils ne peuvent pas récupérer le contenu des fichiers.

link:../mcp/learn-about-mcp.html["Apprenez-en davantage sur l'accès gouverné à l'IA"].



[[who-uses-ai-data-engine]]
== Qui utilise AI Data Engine

Les exemples suivants montrent comment différentes personnes pourraient utiliser AI Data Engine :

* *Administrateurs de stockage* qui doivent examiner les fichiers répondant aux seuils de données froides et obsolètes de leur organisation, identifier les fichiers en double et évaluer les possibilités d'optimisation du stockage.
* *Les équipes d'exploitation informatique* qui ont besoin d'une vue centralisée des données structurées et non structurées présentes dans leur environnement de stockage.
* *Membres de l’équipe Données ou IA* qui utilisent un client IA pour rechercher les métadonnées dans une collection autorisée et pour étiqueter les données avec lesquelles ils souhaitent travailler.
* *Responsables informatiques* qui déploient des outils d'IA et doivent choisir les collections que les clients IA peuvent interroger ainsi que les personnes autorisées à les utiliser.




[[where-ai-data-engine-runs]]
== Là où AI Data Engine s'exécute

Vous accédez à AI Data Engine via NetApp Console, sous *AI data hub > AI Data Engine*. Les services d’analyse et de catalogage s’exécutent sur l’infrastructure que vous fournissez, soit dans votre compte cloud, soit dans votre environnement sur site. Choisissez un déploiement AIDE à nœud unique sur une VM Linux, ou un déploiement AIDE multinœud sur un cluster Kubernetes si votre environnement exige une haute disponibilité à grande échelle.

link:../deploy/deployment-overview.html["En savoir plus sur les options de déploiement"].

AI Data Engine analyse les sources de données prises en charge que vous connectez. Pour plus d'informations, consultez link:../data-sources/connect-data-source.html["Connectez une source de données"].
